# Проверка подключённой версии Beeline v2

Дата: 2026-09-23. Область: три экрана, локальный API, агент, данные организатора. Кейс №11 не входит.

## Источники правил и границы

Использованы frontend-design и актуальные [Web Interface Guidelines](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md). Проверены `index.html`, `styles.css`, `src/app.js` и новый `src/workspace.js`. Сохранена визуальная система; поведение переделано под вычисляемые результаты.

Это не полная сертификация WCAG: axe для новой версии не запускался, реальный скринридер и физический телефон не проверялись. Старые axe-результаты в AUDIT.md относятся только к fixture-прототипу.

## По экранам

| Экран | Проверено и исправлено |
|---|---|
| Аудитория | Явно указано происхождение данных; рекомендации отделены от состава файла. У поиска есть label/name/autocomplete; ввод не пересоздаёт поле и сохраняет фокус. Пустой поиск предлагает сброс. Пагинация возвращает фокус к заголовку таблицы. Показано исключение 100 строк без полной ячейки. |
| Пилоты | Показываются наблюдения среды, включая отрицательные. Реальное ожидание имеет aria-busy, завершение объявляется через live-region. Повторный запрос блокируется в UI и API. Разбор — именованный dialog, Tab удерживается внутри, Escape закрывает и возвращает фокус. |
| План | Прогноз финальных кампаний отделён от evaluator всего прогона. Нет выдуманного бизнес-эффекта. Рискованный fallback требует подтверждения. Экспорт привязан к run_id; устаревший прогон получает 409. Ошибка скачивания выводится текстом, не только цветом. Панели и числа не выходят за 375 px. |

Общие правила: lang=ru, один h1, landmarks, skip-link, aria-current, нативные ссылки/кнопки/select, заметный focus-visible, локализованные числа, перенос длинных значений, reduced-motion CSS. Декоративные знаки скрыты от accessibility tree. Служебный переключатель явно помечен как тест состояний.

## Фактически выполнено

- Chrome через управление браузером: 24 сочетания — 3 экрана × 4 состояния × ширины 375/1440. Во всех один h1 и нет горизонтального переполнения; loading/empty/error имеют ожидаемые заголовки. Это проверка DOM и размеров, не 24 ручных скриншот-ревью.
- Визуально просмотрены основные экраны; мобильные аудитория, пилоты и план проверены на 375 px.
- Поиск без совпадений, сброс с возвратом фокуса, переход на вторую страницу из шести.
- Открытие объяснения Enter, цикл Tab, закрытие Escape и возврат к исходной кнопке. Переход между экранами с клавиатуры.
- Реальный запуск через UI: видимое ожидание, новый run_id, завершённые 20 пилотов и одна кампания на seed 42. После reload восстановлен сохранённый результат.
- CSV и JSON скачаны кнопками с клавиатуры. Файлы в Downloads побайтно совпали с outputs/submission.csv и outputs/run.json. Событие download в браузерном инструменте не подтвердилось, поэтому результат дополнительно проверен по SHA-256 файлов.
- В проверенном связанном сценарии журнал Chrome не содержал ошибок.
- `npm run check` и Prettier check для четырёх UI-файлов прошли.
- 12 тестов агента: адаптация к смене эффектов, сохранение отрицательных наблюдений, ресурсы и отсутствие пересечения финальных ячеек, фактический размер пилота, нулевой бюджет, отсутствие пилотов, пустая аудитория, дубликаты, некорректный baseline, пропущенный сегмент, публичный API, воспроизводимость submission.
- 7 тестов API: повторный запуск, агрегаты без клиентских ID, запрет исходных файлов и path traversal, устаревший экспорт, ошибка worker, Host и Origin.
- 13 оригинальных Python/CSV-файлов пакета сравнены по хешам с источником: различий нет. Agent и runner добавлены отдельно.
- Официальные `local_eval.py --runs 10` и `make_submission.py` выполнены. Два запуска генератора дали SHA-256 CSV `8e85ecc1fec7f8e674eaf5f728d292ece9008557e24a0d1bcf0249d291f2a2a9`.

## Результат и ограничения

На одинаковых seed 0–9 новый агент положителен 10/10, стартовый — 0/10. Медианы: 580 937 и −357 948 у.е. соответственно. Новый алгоритм выигрывает 10/10 сравнений. Все планы укладываются в ресурсы.

Это проверка только на публичной mock-среде. SE эвристическая; история содержит уже совершённые переходы и не доказывает конверсию. Скрытый evaluator и реальные кампании не проверялись. Backend не предназначен для публикации в сети или многопользовательской работы. Рискованный UI-fallback реализован, но текущий положительный seed 42 не покрывает его браузерный сценарий; алгоритмический fallback покрыт тестом.
