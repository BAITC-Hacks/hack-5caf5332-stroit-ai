# Beeline Campaign Studio — подключённый MVP

Рабочее место маркетингового аналитика для кейса №04. Кейс №11 не входит.
UI использует синтетические данные организатора и запускает адаптивного Python-агента в локальной mock-среде. Рабочие цифры больше не заданы UI-fixtures. Реальных рассылок нет.

## Запуск

Python 3.9+; зависимости pandas и numpy. npm нужен только для проверки и форматирования исходников.

```sh
cd beeline/ui
pip install -r requirements.txt
cp engine/run_case.py "../beeline_case_participants (1)/"
python3 server.py --engine "../beeline_case_participants (1)"
```

Открыть <http://127.0.0.1:4173>. Обычный `http.server` не подходит: нужен API агента. `--engine` указывает на папку кейса с `agent.py`, данными и организаторскими скриптами; агент должен заполнять `self.audit` по `docs/AGENT_CONTRACT.md` (пример: `docs/run.example.json`). `engine/agent.py` здесь только эталон контракта, в сабмишен не идёт.

## Сценарий сотрудника

1. **Аудитория:** проверить состав файла, найти тариф или ARPU-группу, запустить подбор.
2. **Пилоты:** увидеть реальные вызовы `env.run_pilot`, включая отрицательные наблюдения, затраты и повторные проверки.
3. **План:** проверить выбранные переходы и каналы, основания и неопределённость; скачать `submission.csv` и `audit.json`.

Кнопка запуска делает вычисление, а не имитирует ожидание. Одновременный повторный запуск заблокирован. После перезагрузки сервис показывает статус или сохранённый результат. Тестовые состояния загрузки, пустоты и ошибки явно подписаны в нижней панели. Поиск, фильтры, страницы и детали отражаются в URL.

## Какие данные использованы

- `engine/customer_profile.csv`: 23 441 строка, baseline 150 641 084 у.е., 63 ячейки тариф × ARPU.
- `engine/data/change_tariff.csv`: 14 823 исторических перехода другой выборки. Используются для ранжирования гипотез, не как вероятность принятия оффера.
- `engine/data/dict_tariff.csv`: тарифный справочник среды.
- Остальные исходные файлы пакета сохранены, но `traffic.csv` и `arpu_monthly.csv` агент пока не использует.

Это файлы кейса, не производственная база Beeline. Хеши использованных данных доступны в audit JSON. Организаторские evaluator, mock-среда и генератор submission не изменены.

## Алгоритм и ограничения

Детерминированный статистический агент, **без LLM**. История формирует короткий список переходов по тарифу и ARPU. Агент исследует гипотезы, повторяет перспективные шумные пилоты и проверяет альтернативные каналы. Следующие действия зависят от наблюдений. Финальный портфель собирается из измеренных непересекающихся ячеек с учётом ресурсов и штрафа за неопределённость.

- `Agent.act` читает только публичный API среды. Внешний evaluator вызывается после решений агента.
- Приближённая SE использует публичное допущение о шуме с запасом 20%; это не откалиброванный доверительный интервал. Пересечение повторных пилотов неизвестно.
- Отрицательные результаты не обрезаются. Если положительных кандидатов нет, контрактный fallback помечается как рискованный; UI требует подтверждения перед экспортом.
- Дубликаты ID или некорректный baseline/ID внутри допустимой ячейки останавливают планирование. 100 строк без полной ячейки исключены: у 95 нет текущего тарифа, у 5 — ARPU-группы. Фильтры финальных кампаний также их не выбирают. В допустимых ячейках 23 341 строка.
- Прогноз UI относится только к финальным кампаниям. Отдельный mock-evaluator учитывает пилоты, расходы и уникальных абонентов.
- Нет гарантии положительного результата на скрытых эффектах организатора или реальной аудитории.

MVP локальный и однопользовательский: loopback, нет авторизации/TLS, отмены вычисления, истории всех запусков, загрузки новых файлов или интеграции с рассылками. Сохраняется последний прогон. Ручное изменение плана отключено, чтобы выгрузка соответствовала оценке.

## Воспроизведение и проверки

```sh
python3 tests/test_agent.py
python3 tests/test_server.py
npm run check
cd engine
python3 local_eval.py --runs 10
python3 make_submission.py
python3 run_case.py --benchmark 10 --out ../outputs
```

Для сдачи: `engine/agent.py` и воспроизводимый `engine/submission.csv` согласно инструкции организатора. Агент использует исторический файл из штатного пакета; без него предусмотрен fallback ранжирования.

Результаты 10 одинаковых seed (0–9), только публичный mock:

| Метрика | Наш агент | Стартовый агент |
|---|---:|---:|
| Медиана net, у.е. | 580 937 | −357 948 |
| Минимум net, у.е. | 169 794 | −1 019 431 |
| Положительных прогонов | 10/10 | 0/10 |

Это локальный benchmark, не результат судейства и не доказанный бизнес-эффект. Полные числа: `outputs/benchmark.json`.

Проверки интерфейса: [AUDIT-CONNECTED.md](AUDIT-CONNECTED.md). Старый `tests/test_ui.py` отключён: он проверял fixture-версию. Старые результаты в `tests/results/` и `AUDIT.md` не доказывают качество новой версии.

## Структура

- `engine/agent.py` — алгоритм и публичный audit решений.
- `engine/run_case.py` — агрегация данных, внешний evaluator, benchmark и артефакты.
- `server.py` — локальный API; экспорт доступен для завершённого текущего прогона.
- `src/app.js` — загрузчик; `src/workspace.js` — подключённый интерфейс.
- `index.html`, `styles.css` — оболочка, визуальная система и адаптивность.
- `outputs/` — последний прогон, CSV и benchmark.
