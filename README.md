# hack-5caf5332-stroit-ai
Hackathon team repository for Stroit AI

## Задача

HackAlem AI 2026, трек 06 «Креативные индустрии», кейс Firebird: **умный подбор event-подрядчиков**.

Сервис по городу, дате, типу мероприятия, категории и бюджету возвращает до трёх подрядчиков из каталога. У каждого подрядчика конкретное объяснение, почему он подходит. Занятые на дату исключаются, а пустой результат объясняется словами.
