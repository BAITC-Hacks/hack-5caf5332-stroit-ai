# hack-5caf5332-stroit-ai
Hackathon team repository for Stroit AI

HackAlem AI 2026, команда Stroit AI. Два кейса:

## 1. Beeline: Tariff Marketing Campaigns

Агент, который выбирает, кому предложить смену тарифа, проводит пилоты и собирает план кампаний в рамках бюджета, не разоряя компанию по дороге.

- `beeline/beeline_case_participants (1)/` — агент (`agent.py`), локальная проверка (`local_eval.py`), генерация `submission.csv`, дашборд прогона `flow.html`. Ключи не нужны.
- `beeline/ui/` — интерфейс Beeline Campaign Studio: аудитория, пилоты, план. Запуск: `cd beeline/ui && python3 -m http.server 4173`, открыть http://127.0.0.1:4173. Без сборки и ключей.

## 2. «Аким на 5 часов»: AI-симулятор управления городом

Sim Astana: единый бюджет, 14 мер по 5 направлениям, расчёт Astana QoL Score по датасету организатора, карта районов и мнение жителей.

- `akim/ui/` — приложение. Запуск: `cd akim/ui && npm ci && npm run dev`. Тесты: `npm test`. Ключи и внешние сервисы не нужны.
- `akim/` — ТЗ, датасет и описание проекта.
