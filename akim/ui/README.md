# Аким на 5 часов

«Аким на 5 часов» — симулятор решений акима Астаны. Игрок знакомится с задачей, выбирает приоритеты и собирает на карте пять мер из четырнадцати, распределяя бюджет между районами. По мере выбора меняется балл качества жизни, на карте живут 2 000 синтетических жителей. Итог показывает достижение целей, вклад каждой меры, изменения показателей районов, поддержку жителей и возможную замену для улучшения плана.

AI-аким помогает сравнить решения: советник предлагает одну замену, автопилот собирает план, а серверный режим `goal` подбирает меры по цели и ограничениям. В текущей панели доступны советник и автопилот; цель передаётся через API `/api/akim`. «Спросить жителей» оценивает реакцию синтетических жителей на предложение или готовый план; с AI доступны разбор свободного вопроса и поиск публичных публикаций Threads. Мнения жителей и эффекты мер — результаты модели, а не реальный опрос или прогноз города.

## Как запустить

Нужен Node.js 22 или новее. Из папки `akim/ui`:

```sh
npm install
npm run dev
```

Откройте http://127.0.0.1:5173. Команда запускает Express API на порту 8791 и Vite с прокси `/api`. Без ключа работают игра, расчёт баллов, локальный опрос, советник и автопилот на детерминированном движке. Режим `goal` без ключа принимает структурированные ограничения `constraints`.

`OPENAI_API_KEY` необязателен. Передайте его серверу через окружение, прочитав из macOS Keychain или файла в `~/.secrets/` с правами `600`; не записывайте ключ в репозиторий или переменные `VITE_*`. Например, если в Keychain уже есть запись сервиса `OPENAI_API_KEY`:

```sh
export OPENAI_API_KEY="$(security find-generic-password -s OPENAI_API_KEY -w)"
npm run dev
```

С ключом доступны объяснения итогов, AI-аким и ответы жителей через `gpt-6-luna` (модель по умолчанию в `server/llm.ts`). Числовые результаты по-прежнему вычисляет движок; AI объясняет и выбирает среди проверяемых решений. `OPENAI_MODEL` позволяет задать модель на сервере.

Для собранной версии:

```sh
npm run build
API_PORT=8791 npm start
```

Express отдаёт интерфейс из `dist/` и API по адресу http://127.0.0.1:8791. Порт можно поменять через `API_PORT`; при разработке одновременно измените адрес прокси в `vite.config.ts`. `npm run preview` запускает только статический просмотр сборки.

## Деплой Worker

Конфигурация — [wrangler.jsonc](wrangler.jsonc), точка входа — `worker/index.ts`. Один Cloudflare Worker обслуживает `/api/*` и статические файлы `dist/`; остальные маршруты обрабатываются как SPA. В конфигурации заданы KV `CACHE`, ограничения запросов `AI_LIMIT` и `SERVICE_LIMIT`, модель `gpt-6-luna`.

После авторизации Wrangler в нужном аккаунте:

```sh
npx wrangler login
npx wrangler secret put OPENAI_API_KEY
npx wrangler secret put SESSION_SECRET
npm run deploy
```

Секреты вводятся интерактивно: возьмите ключ и случайный `SESSION_SECRET` из своего хранилища секретов. Текущий `wrangler.jsonc` объявляет оба секрета обязательными для деплоя. Для другого аккаунта создайте KV командой `npx wrangler kv namespace create CACHE` и замените его ID в конфигурации. `npm run deploy` сначала собирает интерфейс, затем запускает `wrangler deploy`.

Проверка Worker без публикации: `npm run check:cloud`. После изменения bindings обновите типы командой `npm run types:cloud`. Для локального Worker нужны готовый `dist/` и переменные `OPENAI_API_KEY` и `SESSION_SECRET`, прочитанные из хранилища секретов в окружение. Команда `CLOUDFLARE_INCLUDE_PROCESS_ENV=true npm run dev:cloud` передаст их Wrangler и запустит Worker на порту 8792.

## Структура

- `index.html`, `src/main.tsx` — единственная HTML-страница и точка входа React.
- `src/game/` — игровой сценарий (`Game.tsx`), выбор мер района (`DistrictPanel.tsx`), пять решений и бюджет (`Tray.tsx`), подписи и стили.
- `src/planner/Report.tsx`, `Matrix.tsx`, `ScoreGauge.tsx`, `analysis.ts` — итоговый отчёт, матрица показателей, шкала балла и расчёты для интерфейса.
- `src/planner/planner-sheet.css` — единственный источник стилей отчёта. Редактируется напрямую; переменные заданы на `.sheet`, селекторы изолированы префиксом `.sheet`.
- `src/engine.ts`, `data.ts`, `money.ts` — правила, синтетические данные и стоимость мер.
- `src/CityMap.tsx`, `geography.ts`, `astana-districts.json`, `astana-roads.json` — карта, геометрия районов и граф улиц.
- `src/population.ts`, `profiles.ts`, `residents.ts`, `ResidentCard.tsx` — население, распорядок и модель мнений.
- `src/AskPanel.tsx`, `AkimPanel.tsx`, `CityDataPanel.tsx`, `ThreadsResults.tsx` — панели опроса, AI-акима, источников и публикаций.
- `src/services.tsx`, `city-data.ts`, `threads.ts` — клиент API и типы; `src/PlanBuilder.tsx` содержит только общий форматтер `fmt` для панелей.
- `src/styles.css` — общие стили, панели и карта; `public/` — изображения жителей и лицензия.
- `server/` — Express API, интеграция с моделью, поиск плана по цели, опросы, объяснения, источники данных и локальный кеш.
- `worker/index.ts`, `worker-configuration.d.ts`, `wrangler.jsonc`, `tsconfig.worker.json` — Cloudflare Worker, типы и конфигурация.
- `tests/`, `playwright.config.ts` — модульные и браузерные проверки.
- `scripts/prepare-roads.ts` — подготовка графа улиц; `docs/MAP.md` и `docs/ATTRIBUTION.md` — происхождение карты и лицензии.

## Тесты

```sh
npx tsc --noEmit
npm test
npm run build
npx playwright test --project=desktop
```

`npm test` запускает 37 тестов движка, серверной логики, населения и анализа плана. Для трёх актуальных игровых сценариев:

```sh
npx playwright test tests/flows.spec.ts --project=desktop --reporter=line
```

Playwright сам запускает Vite на порту 5178. Нужен установленный Chromium: при первом запуске используйте `npx playwright install chromium`. Сценарии `flows.spec.ts` подменяют API и тайлы карты, ключ OpenAI не нужен. Полный desktop-прогон также включает `tests/live-ui.spec.ts`: в нём остались проверки элементов прежнего интерфейса, поэтому его нужно отдельно актуализировать.

## Правила движка

Исходные требования: [данные и формулы](../file.md), [техническое задание](../tz.md), [контекст проекта](../PROJECT.md).

- План содержит ровно пять уникальных мер, стоит не более 100 условных единиц и включает не более двух мер каждого направления. Районные меры требуют район, городские применяются ко всему городу; конфликты проверяются до расчёта итогового балла.
- Эффекты за два года учитывают задержку: `эффект × (8 − lag) / 8`. Фиксированные синергии не уменьшаются задержкой. Показатели ограничены диапазоном 0–100.
- Балл города: `0,7 × средний балл районов с весами населения + 0,3 × балл худшего района − число показателей строго ниже 40`. Недопустимый план не получает итоговый балл.
- Исходный балл — `52,55768`. Пример M7, M8 и M10 в Нуре, M12 для города и M5 в Сарыарке стоит 95 у.е. и даёт `56,54307`.
- Локальный советник перебирает допустимые одиночные замены; автопилот выполняет до восьми улучшений. Глобальный оптимум не гарантируется.

Справочные суммы в миллионах тенге из `src/money.ts` не заменяют игровой бюджет. Погода, воздух и другие внешние источники дают контекст, но не перезаписывают синтетические индексы и эффекты мер. Опрос вычисляет мнения вымышленных жителей; публикации Threads служат отдельным контекстом, а не репрезентативной выборкой.


## Проверка «Что если»

На итоговом листе доступны паводок, отключение ТЭЦ и рост цен на 20%.
Это условные события для сравнения устойчивости, не прогноз реальных ЧП.
Точные изменения районных показателей показаны рядом с переключателем;
они применяются после эффектов мер, перед ограничением 0–100 и исходной формулой Score.
Вклад меры — разница с тем же событием без этой меры, без дополнительных бонусов защиты.
При росте цен стоимость умножается на 1,2; если превышены 100 у.е., балл не считается.
Сохранённый план, обычный балл и варианты сравнения при этом не меняются.


## Записка руководству

На итоге нажмите «Скачать записку»: откроется системная печать, где можно сохранить PDF.
Печатная версия на одном листе A4 содержит пять мер и их стоимость, балл, цели,
главные улучшения и риски, районные результаты и поддержку локальной модели жителей.
Карта и элементы управления в печать не попадают. Записка отражает обычный план,
без выбранного стресс-события; поддержка явно обозначена как синтетическая.
