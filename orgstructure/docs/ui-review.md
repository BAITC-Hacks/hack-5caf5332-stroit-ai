# Проверки UI

Основа: frontend-design и Web Interface Guidelines
https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md

Палитра: бумага #ffffff, фон #f3f6f8, текст #18324c, акцент #087773,
границы #d3dfe5, риск #a23b27. Avenir Next / Segoe UI / Arial без сетевых шрифтов.
Основа композиции — пара редакций и прослеживаемость ответственности.
Вместо декоративного дашборда первый экран открывает реальную задачу сравнения.

H1, экран загрузки: проверены labels, native file inputs, keyboard focus,
skip link, aria-live, inline errors, SVG aria-hidden, адаптивная сетка 375px,
reduced motion, читаемость длинных имён файлов. Нарушений при ревью кода нет.

H2, таблица функций и цитаты: static/app.js — labels у фильтров,
кнопки вместо кликабельных div, native dialog (Escape и возврат фокуса),
статус не только цветом, query params для фильтров, горизонтальный скролл
ограничен таблицей, content-visibility для строк. static/style.css —
видимый focus, перенос длинных имён, мобильные цитаты одной колонкой.
Нарушений при ревью кода нет.

H3, сводка: числа с tabular-nums, ссылки на основания через кнопки,
счётчики структурных подразделений отделены от ролей.
H3, схема: native buttons у узлов, SVG декоративный, текстовый список
переносов дублирует линии и доступен на 375px.
H3, риски: статус и приоритет текстом; профилактические нормы отделены
от возможных нарушений, цитаты всех участников доступны в dialog.
Проверено по свежей версии Web Interface Guidelines. Нарушений в коде нет.

H4, метод и экспорт: ссылки скачивания имеют понятные имена и native download,
HTML автономный, ошибки экспорта имеют JSON с инструкцией. Реальный прогресс
передаётся по NDJSON, время измеряется отдельно от воспроизводимого отчёта.

Браузерная проверка Chrome:
- Демо строит сводку, схему, функции, риски и ссылки экспорта; console errors нет.
- На 375px document.scrollWidth = innerWidth = 375, включая окно цитат.
- Фильтр moved + поиск «взаимодействует с субъектами» оставляет нужную строку.
- Две цитаты показывают §5.4.4 и §5.3.3, владельцев и абзацы 175 / 164.
- Escape закрывает native dialog; поиск без совпадений даёт понятное пустое состояние.
- Проверены desktop screenshot загрузки и сводки.

При финальном ревью исправлен фильтр узлов схемы: ДИТААД и ДОА показывают также
функции совместного владельца «ДИТААД / ДОА». Полные предложения заголовков сокращены
до названия владельца в схеме; исходные цитаты сохранены.

Ограничение браузерной проверки: file chooser открылся, но автоматическая установка
файла была остановлена браузерным инструментом — запрос разрешения закрыт без решения.
Этот сценарий не отмечается как пройденный. Обход не выполнялся. Multipart DOCX,
невалидные файлы и ошибки сервера отдельно покрыты API/unit-тестами.
